Middle Powers Leverage Map

Which of ten middle powers hold something frontier AI developers cannot easily replace, and which small groups of them hold enough of it to set a condition together. Every cell has a source link, a confidence flag and a reason.

Read before using. This is a first pass built in about a day from public sources. Only two cells reach the top score, and both are chips. All Algorithms cells score 1. One cell has no score because no source was found (hatched). Some figures come from secondary summaries and are marked Single source or Unverified. Treat the coalition ranking as a way to ask questions, not as a finding.

How this works

  1. Read the grid. Each row is a country and each column is a part of the AI supply chain. The number is how hard that country's contribution is to replace, from 0 to 3.
  2. Check the evidence. Select any cell to see what the country holds, why it got that score, how well it is sourced, and the link.
  3. Look for groups. The coalition finder ranks groups of 3 or 4 countries by what they hold together. Select a row, or press Play tour, to see the group's links and which member holds each layer.
  4. Test the result. Tick the box to score unverified cells as 1 and see whether the top group changes.

The map

Seven layers. Score 0 to 3 for how hard the lever is to replace. Select a cell for the evidence.

Coalition finder

Pick the countries that might act together, choose a group size, and see which groups cover the most layers. Coverage of a layer is the highest score any member holds in it.

Select a row to show that group. Each bar is the highest score any member holds in that layer.

Ranking order. 1) number of chokepoint (3) cells held, 2) number of layers where the group reaches 2 or more, 3) total coverage, 4) number of cells scoring 2 or more. Ties at the top are shown, not hidden.
